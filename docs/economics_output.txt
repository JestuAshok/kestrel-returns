--- 7.2 Precision and Recall Needed to Reach 95% Accuracy (at 11.4% Return Rate) ---
Mathematical Derivation:
  Let r = 0.114 (11.4% actual return rate), N = 100 orders.
  Total Positives (Returns) = 11.4, Total Negatives = 88.6.
  To achieve 95% accuracy, total classification errors must not exceed 5.0% of all orders:
      Errors = False_Negatives (FN) + False_Positives (FP) <= 5.0
  FN = 11.4 * (1 - Recall)
  FP = (11.4 * Recall) * (1 - Precision) / Precision
  Errors = 11.4 * (1 - Recall) + 11.4 * Recall * ((1 - Precision) / Precision) <= 5.0

Boundary Analysis:
  - If Recall = 0 (Predict Always 0): FN = 11.4, FP = 0 -> Error = 11.4% -> Accuracy = 88.6% (Cannot reach 95%).
  - To reach 95% accuracy, False Negatives ALONE must be <= 5.0:
      11.4 * (1 - Recall) <= 5.0  ==>  Recall >= 1 - (5.0 / 11.4) = 56.14% (Minimum required Recall!)
  - Even at perfect 100% Recall (FN = 0), FP must be <= 5.0:
      11.4 * (1 - Precision) / Precision <= 5.0  ==>  Precision >= 11.4 / (11.4 + 5.0) = 69.51% (Minimum Precision at 100% Recall!)
